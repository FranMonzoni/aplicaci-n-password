# Evaluador de Fortaleza de Contraseña

Este proyecto es una aplicación web desarrollada en **React** que permite evaluar la fortaleza de una contraseña ingresada por el usuario, así como generar contraseñas aleatorias con diferentes configuraciones.

## Funcionalidades

- Ingreso de contraseña con botón de mostrar/ocultar.
- Clasificación de la fortaleza: **Poco segura**, **Segura** o **Muy segura**.
- Botón para copiar la contraseña al portapapeles.
- Mensaje temporal confirmando el copiado.
- Botón para generar contraseña aleatoria.
- Panel avanzado con configuraciones personalizadas:
  - Largo de la contraseña.
  - Incluir o no letras minúsculas.
  - Incluir o no letras mayúsculas.
  - Incluir o no números.
  - Incluir o no caracteres especiales.
